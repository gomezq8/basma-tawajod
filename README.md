# بصمة التواجد

تطبيق أندرويد: أول ما توصل موقع الدوام يحسب وقت بصمة التواجد ويرن لك وقتها.

## طريقة الحساب
- دخول قبل 07:00 ← ينحسب 07:00
- دخول بين 08:00 و 08:30 ← ينحسب 08:00
- غير كذا ← ينحسب وقت وصولك الفعلي
- بصمة التواجد = وقت الدخول المحسوب + ساعتين ودقيقة + 4 دقايق هامش (المجموع ساعتين و5 دقايق)

كل هالأرقام تقدر تغيرها من داخل التطبيق.

## التثبيت على جوالك
1. نزّل Android Studio من developer.android.com/studio وثبته.
2. فك ضغط المجلد، وافتح Android Studio ← Open ← اختر مجلد `BasmaApp`. انتظر لين يخلص التحميل (أول مرة تاخذ دقايق).
3. في الجوال: الإعدادات ← حول الهاتف ← اضغط "رقم الإصدار" 7 مرات. بعدين خيارات المطور ← فعّل "تصحيح USB".
4. وصّل الجوال بالكمبيوتر بالكيبل، واضغط زر التشغيل ▶ الأخضر في Android Studio.

(لو تبي ملف APK ترسله لجوالك: Build ← Build App Bundle(s) / APK(s) ← Build APK(s).)

## قراءة بصمة Ringo HR (الأدق)
لما تبصم دخول في Ringo ويطلع "تم تسجيل الدخول"، التطبيق ياخذ هالوقت بالضبط ويحسب التواجد منه.
- فعّلها من زر "⭐ قراءة بصمة Ringo HR" داخل التطبيق (إمكانية الوصول ← التطبيقات المثبتة ← بصمة التواجد).
- لو أندرويد قال "إعداد محظور": معلومات التطبيق ← ⋮ فوق ← "السماح بالإعدادات المحظورة"، وارجع فعّلها.
- يقرأ شاشة Ringo بس. وقت Ringo يغلب وقت الـ GPS، والإدخال اليدوي يغلب الكل.

## أول استخدام
1. افتح التطبيق وأعط الصلاحيات الأربع بالترتيب (الموقع، "السماح طوال الوقت"، الإشعارات، البطارية).
2. وأنت في الدوام اضغط "أنا الحين في الدوام — احفظ الموقع".
3. خلاص. كل يوم أول ما توصل يطلع لك إشعار بوقت البصمة، ويرن وقتها.

## ملاحظات
- لو تأخر تحديد الوصول (GPS ضعيف داخل المبنى)، اضغط "بصمت دخول الحين" أو "أدخل وقت الدخول يدوي".
- أجهزة سامسونج وشاومي وهواوي تقفل التطبيقات بالخلفية بقوة: من إعدادات البطارية خلّ التطبيق "غير مقيد".
- يتجاهل الجمعة والسبت تلقائياً (تقدر تغيرها).
